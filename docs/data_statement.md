# Data Statement

This project uses the eICU demo v2.0.1 dataset only. The verified cohort has
2,520 raw ICU stays from 1,841 patients across 186 hospitals and 292 wards.

The repository does not commit raw CSVs, processed patient streams, tokenized
patient artifacts, or model checkpoints. Those outputs remain local in ignored
directories.

Public artifacts are limited to cohort summaries, experiment comparisons, final
aggregate results, selected configuration snapshots, and figure files derived
from aggregate metrics.

No public artifact exposes patient identifiers, stay identifiers, token
sequences, or raw rows.
