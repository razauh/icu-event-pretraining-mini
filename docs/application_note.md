# Application Note

This repository is a technical prototype for ICU event-stream pretraining on
the eICU demo v2.0.1 dataset. It demonstrates reproducible event construction,
leakage-aware evaluation, patient-grouped benchmarking, hospital-grouped
benchmarking, and a simulated-client FedAvg analysis.

The verified demo cohort contains 2,520 raw ICU stays from 1,841 patients
across 186 hospitals and 292 wards. All public text and figures should stay
within that scope and should not imply clinical readiness or generalisation to
other hospitals.

Use the project as exploratory research material, not as a deployed clinical
model.
